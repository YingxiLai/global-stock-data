# Open-source and MCP reuse decisions

Review date 2026-10-07. Core remains standard-library-only and independently testable. Source code licensing never supplies market-data entitlements.

| Component | Decision in this iteration | Evidence and boundaries |
|---|---|---|
| Official MCP Python SDK 2.3.0, MIT | Installed optional extra, exact/transitive hash lock, tested in-process and real stdio subprocess | [Pinned manifest](https://github.com/modelcontextprotocol/python-sdk/blob/v2.3.0/pyproject.toml), [license](https://github.com/modelcontextprotocol/python-sdk/blob/v2.3.0/LICENSE); two pure tools plus operator-scoped research_fetch for the reviewed SEC/Treasury/CFTC adapters; no HTTP server/discovery/account or host installation |
| EdgarTools 5.61.1, MIT | Candidate only; not installed | [Release](https://github.com/dgunning/edgartools/releases/tag/v5.61.1), [manifest](https://github.com/dgunning/edgartools/blob/v5.61.1/pyproject.toml). Plain parser extra could help future XBRL/13F parsing; [ai] requires MCP <2 and cannot share the v2 SDK environment. Local-first does not guarantee offline cache misses; avoid upstream YAML/VCR fixtures |
| TA-Lib 0.8.1, BSD wrapper/C library | Candidate offline indicator reference; not installed or used to claim parity | [Release](https://github.com/TA-Lib/ta-lib-python/releases/tag/v0.8.1). Prefer pinned batch Function API with explicit smoothing/seed/lookback and own goldens. Stream semantics and defaults have changed; no provider data license included |
| OpenBB v5, Apache-2.0 | Design inspiration only; no source copied and no runtime imported | [License](https://github.com/openbq-org/OpenBB/blob/openbb-v5.0.0/LICENSE), [metapackage](https://github.com/openbq-org/OpenBB/blob/openbb-v5.0.0/openbb_platform/pyproject.toml). Full package would auto-introduce providers including Cboe/FINRA and service/config overhead; project-owned capability boundary is smaller |
| Financial Datasets MCP | Deferred | [Public source](https://github.com/financial-datasets/mcp-server), [vendor terms](https://www.financialdatasets.ai/terms-of-use). Older public server/lock differs from hosted product; data key, plan eligibility, AI/cache/export terms require separate approval; no current connection or purchase |
| Massive MCP | Deferred | [Source](https://github.com/massive-com/mcp_massive), [data terms](https://massive.com/legal/market-data-terms-of-service). Provider entitlements required; table mutations and endpoint discovery would need narrowing; no token/HTTP endpoint/account connected |

MCP 2.3.0 source/API and official PyPI distribution were checked before isolated installation. The dependency closure is pinned in uv.lock and requirements-mcp-dev.txt; this is reproducibility, not an assertion of a vulnerability-free closure. SDK [SSRF advisory](https://github.com/modelcontextprotocol/python-sdk/security/advisories/GHSA-rwrf-2pqf-9j8j), [body limits](https://github.com/modelcontextprotocol/python-sdk/security/advisories/GHSA-fmmv-w9g8-j3gc), and [audience validation](https://github.com/modelcontextprotocol/python-sdk/security/advisories/GHSA-w4fh-qvv9-3v23) inform future HTTP/client review. This fork exposes neither an external MCP client nor HTTP transport; input/output budgets are explicit. SDK ToolAnnotations are descriptive, not an authorization mechanism.

No external project's public CI result is presented as this fork's test result. Candidates have not been executed. A future backend must preserve the canonical Record/evidence schema, source policy, failure statuses and aggregation budget; its fallback/discovery must never activate denied providers. Every new permission, paid subscription, credential or financial account remains a separate human decision.
